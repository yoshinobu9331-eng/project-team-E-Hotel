【在庫重量モニター 試作版】

■ Excelの準備
同じフォルダに「商品管理.xlsx」を置き、1行目に次の列名を作成してください。
sensor_id | 商品名 | 型番 | 価格 | 通知閾値_g

2行目以降に商品を入力します。例：
S01 | 商品A | A-001 | 1200 | 150
S02 | 商品B | B-002 | 2500 | 200

sensor_idは商品ごとに重複しない値にしてください。
重量と通知閾値の単位はグラム(g)です。

■ 管理用PCで起動
1. Pythonをインストール
2. このフォルダでコマンドプロンプトを開く
3. pip install -r requirements.txt
4. python main.py
5. PCのブラウザで http://127.0.0.1:5000 を開く

別PCから見る場合は、管理用PCのIPアドレスを使って
http://管理用PCのIPアドレス:5000
を開きます。同じネットワーク内であること、ファイアウォール設定が必要です。

■ ラズパイの送信テスト
1. raspi_sender_test.py の PC_IP を管理用PCのIPアドレスに変更
2. ラズパイで pip install requests
3. python raspi_sender_test.py

■ 実センサーを接続するとき
raspi_sender_test.py の weight を作っている部分を、
実際のセンサーから読み取った重量に置き換えます。
センサーの型番・接続方式によって読み取りコードは異なります。

■ 注意
・この試作版は重量データと通知状態をPCのメモリに保持します。
  PCプログラムを終了すると、受信重量・通知状態はリセットされます。
・Excelを変更した場合、ブラウザを更新すれば商品情報が再読み込みされます。
・この版は動作確認用です。長期運用する場合はデータ保存や通信認証などを追加してください。
